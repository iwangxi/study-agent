# OCR 识别

光学字符识别（Optical Character Recognition, OCR）是一种将图像中的文字转换为可编辑、可搜索数据的技术。

## 应用场景

- 文档和书籍数字化
- 票据和表单处理
- 车牌和身份证识别
- 移动端实时翻译

## 推荐学习资源

- [Tesseract OCR](https://github.com/tesseract-ocr/tesseract) - 历史悠久的开源 OCR 引擎
- [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) - 基于深度学习的多语言 OCR 系统
- [Awesome OCR](https://github.com/kba/awesome-ocr) - 精选 OCR 相关工具与文章
